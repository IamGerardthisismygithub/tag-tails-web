# Tag-Tails website — design preview

Landing page proposal for [tag-tails.co.uk](https://tag-tails.co.uk). Static HTML, no build step: open `index.html`.

- Languages: English (UK, default), Español, Français, Deutsch, Italiano, Português — picked from the visitor’s device language, switchable in the footer.
- Light and dark mode follow the device setting.
